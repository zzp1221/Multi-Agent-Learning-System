# Maintenance

This directory stores operational notes for keeping the LLM-Wiki healthy.

- [[lint_checklist]]: recurring checks.
- [[error_book]]: repair queue for broken links, weak evidence, contradictions, stale claims, and retrieval failures.
- `reports/`: optional human-readable lint or benchmark summaries.

Maintenance pages are excluded from RAG wiki imports.
